### 1.1 怎么自己复现

1. 取 645 份 manifest（AutoDL 数据盘 / 文件存储盘，路径见白名单的 `source_roots`）；
2. 检出所选基准的产出 commit（原始重放用 `40826a2`，新接线重放用 `7ee6a30`）；
3. 把白名单 `batches[].root` 改写成你自己的副本路径——**直接沿用原值会找不到**，
   因为那记的是执行机本地的 Windows 路径；
4. 按 [`p2_2_delivery.md`](p2_2_delivery.md) §7 跑三个入口；
5. 与基准文件比对 `inputs.total.tree_sha256`（先确认读的是同一批字节），
   再比对 `artifacts` 的逐文件摘要。

**比对顺序不能颠倒。** 树摘要不一致时，结果差异应归因于输入而非代码；先比产物摘要会把
输入问题误记为代码问题。树摘要的算法写在基准文件的 `inputs._tree_digest_recipe` 里，
不依赖任何脚本即可重现。

### 1.2 一条必须守住的界限

本文件里由脚本自动产生的部分（覆盖计数、门禁结论、摘要比对）是**证据生产方的自动复现**，
不是任何人的判断。复核人在 §4 签的是**本人回查原始来源后作出的判断**，签署记录按此措辞引用，
不把自动结论冒充为人工复核。清单里凡要求「回查来源」的动作，均指亲手核对，不得以复述本文档代替。

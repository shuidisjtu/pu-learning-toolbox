# 分布漂移感知 PU 补充清单

本清单跟踪[设计说明](distribution_shift_aware_pu.md)中的现有能力和待验证的研究问题。
`[x]` 表示已有实现和对应证据，不等同于论文数值复现。

## A. 漂移审计与重要性权重

- [x] 核对边际密度比与论文联合密度比的区别，限定协变量漂移及覆盖假设。
- [x] 校验源域、目标域特征和行对齐的 PU 标签；目标域标签可省略。
- [x] 用 OOF 域预测计算 AUC，另拟合域分类器，导出与源域行对齐的均值归一化权重。
- [x] 报告 ESS、分位数、概率裁剪率、权重上界触及比例及覆盖警告。
- [x] 检查覆盖不足或没有目标域标签时的 `adaptation_ready`；审计本身仍可用。
- [x] 覆盖同分布、均值漂移、极端权重和非法输入测试。

## B. 独立 CLI 与部署诊断

- [x] `shift-audit` 支持带表头 CSV 与 `.npy` 图像特征，导出 JSON、Markdown 和源域权重 CSV。
- [x] `shift-monitor` 保存固定参考域下的窗口历史、相邻突跳和分级告警。
- [x] `review` 对可信的已拟合模型输出拒绝预测、覆盖率和人工复核队列。
- [x] 分域解析或估计类先验，分解平均标记倾向变化；提供双域先验敏感性和不可行假设诊断。
- [x] 用行级 bootstrap 传播先验、标记率及倾向的不确定性。
- [x] 用 CLI 文件旅程和最小示例说明：漂移检测、加权训练与目标域验证是不同的任务。

## C. 联合漂移研究

- [x] 实现软类别条件密度比、先验比、有界相对联合权重及其与 PU 分类器的交替更新。

- [x] 提供同时改变类先验和类条件分布的合成 smoke，以及 `trPU`、`tePU`、fine-tune、MMD、

- [x] 提供公开表格数据的多种子 smoke、95% CI 与样本重叠审计。
- [ ] 增加覆盖概念漂移、支持集断裂和无漂移退化的完整统计协议。
